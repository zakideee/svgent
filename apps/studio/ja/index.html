エージェントとの会話を創作。画像/動画に残す

ユーザーの入力とエージェントの動きを台本にして、セッション画面を animated SVG で組み立てます。動画、静止画、ページ分割でも書き出せます。

こんな人に

  • 開発する人

    実装やレビューの流れを、README や PR に貼れる形で。実際のセッションも、秘匿情報を外した要約として出せる。

  • 発信する人

    告知や自作物の紹介を、投稿に収まるサイズで。目を引く一枚にも、短い動画にも。

  • 教える人

    手順の見本を、スライドや教材に。画面収録が難しい場面でも、同じ流れを描ける。

会話に書けるもの

  • Markdown

    見出し、リスト、表、syntax highlight付きのコード、diff。

  • 画像埋め込み

    添付した画像と、生成された結果。

  • エージェントの動き

    tool の実行、選択肢、承認。

  • ユーザー入力

    音声入力、IME 変換、補完。

見せ方で選べるもの

  • アプリとターミナル

    作り手が慣れ親しんだインターフェイスを選べる。

  • 配色と大きさ

    テーマ、背景、文字サイズ、余白。

  • アニメーション

    ユーザーが打つ速さ、エージェントが返す速さ、間の取り方。

  • カメラ

    タイムラインから自動計算される追従ズーム。

  • ページ

    通しで1本にするか、スライドに分割するか。

書き出し形式

SVG・PNG・WebP・GIF・MP4

❯ pnpm render session.json --strict

  • poster-svg
  • animated-svg
  • poster-png
  • poster-webp
  • animated-webp
  • gif
  • mp4
  • transcript-svg
  • transcript-png
