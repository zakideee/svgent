Compose an agent session. Keep it as images / video.

Script what the user types and what the agent does, and the session is built as an animated SVG. Video, stills and slides come out of the same script.

Who it is for

  • People who build

    An implementation or a review, in a form a README or a PR can hold. A real session can go out as a sanitised summary.

  • People who publish

    An announcement, or your own tool introduced, at the size a post wants — as one image or a short video.

  • People who teach

    A worked example for slides and courses, drawn even where recording the real screen is not an option.

What a session can say

  • Markdown

    Headings, lists, tables, code with syntax highlighting, diffs.

  • Embedded images

    Ones you attach, and ones the session generates.

  • Agent activity

    Tool runs, choices, approvals.

  • User input

    Voice, IME conversion, completions.

What you choose about the look

  • App or terminal

    Pick the interface you are used to working in.

  • Colour and size

    Theme, backdrop, text size, margins.

  • Animation

    How fast the user types, how fast the agent answers, how long the pauses run.

  • Camera

    A follow zoom computed from the timeline.

  • Flow

    One scrolling piece, or split into slides.

Export formats

SVG, PNG, WebP, GIF, MP4

❯ pnpm render session.json --strict

  • poster-svg
  • animated-svg
  • poster-png
  • poster-webp
  • animated-webp
  • gif
  • mp4
  • transcript-svg
  • transcript-png
