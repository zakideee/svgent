# Showcase scripts

Every script here is fictional (`basis: fictional`, the default) and was
written for svgent under the same script rules `list_presets` returns to an
agent at runtime. No session material of any kind was used.

| File                    | Written for                     | Notes                                                  |
| ----------------------- | ------------------------------- | ------------------------------------------------------ |
| `share-safely.json`     | A clip for the team channel     | App surface, follow camera                             |
| `deny-repro.json`       | When a decline was missed       | Terminal surface, a denied approval, voice input       |
| `approvals-slides.json` | Choices and approvals, 3 slides | Transparent slides, a kept choice menu, a held thought |
| `mcp-readme.json`       | Your MCP, in the README         | Link-card size, a completion in the composer           |
| `app-image.json`        | App · image generation          | Copy of `examples/readme-en-app-image.json`            |
| `terminal-camera.json`  | Terminal · camera               | Copy of `examples/site-hero-en-tui-zoom.json`          |
| `ja-ime.json`           | 日本語 · IME typing             | Copy of `examples/readme-tui-zoom.json`                |

The three copies mirror files under `examples/`, whose provenance is recorded
with the studio's own samples; a workspace app imports only its own files.
When an example changes, copy it again.
